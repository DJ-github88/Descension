## Carry-forward lessons from C1

- Test closed boundaries positively and negatively: unknown/nested fields stay raw drafts; valid recovered/rested state must still import. Historical event facts are not current-zone invariants.

- Separate prospective add-pick checks from completed-build validation. Count same-tree points, full predecessor ranks and actual paid grants; lowering level/respec must remove eligibility immediately.
- Fixed mapping and branch result survive all interruption/void paths. A rejection/exception or zero-exit observation runner is not a passing assertion.
- Test on actual inherited routes/styles. A scoped stylesheet can still lose to a more specific global gradient; measured mounted colors/focus/touch targets matter.
- Counts97/54 and green negative probes are useful evidence, never sufficient semantic acceptance. Keep complete records while adapting the established system.
