# Creator decision — Druid, name only

**DESIGN INTENT — approved by the creator, superseding earlier naming proposals.**

- The transformation class's player-facing name is **Druid**.
- **Metamorph is rejected** as its player-facing name. Shapeshifter and other alternatives remain records of earlier discussion, not active naming choices.
- The core fantasy remains **bodily transformation and adaptation**. The name does not import conventional Druid rules, nature worship, companion requirements or native heritage assignments.
- The proposed anatomical economy, Predator/Adaptive Bastion/Mimic specializations and proposed native origins remain under HeadQ review. Name approval is not mechanics, content, balance or roster approval.
- Existing **Shaper IDs, resources, spell/talent references, saves, art and compatibility remain intact** until an explicit migration is approved. No application implementation is authorized.

## Approved general naming principle

Selectively use recognizable established class names when they help players understand the roster. Familiarity is useful, not a requirement to make every name conventional. Distinctive mechanics, specialization behavior and Mythrill cultural origins remain the primary appeal. A name never imports another game's class package or automatically dictates access.

## Planning identifiers and historical evidence

The existing dossier remains at `classes/transformation-class.md`. R1 draft-only technical keys such as `metamorph`, `metamorph-body`, `cr1_metamorph_*` and the existing JSON filename are retained as internal proposal identifiers, **not player-facing labels or approved final application IDs**. This naming decision does not authorize their migration. Display metadata now identifies their class as Druid.

Historical Formbender specializations actually named Metamorph, archived investigation drafts, raw source snapshots and old review evidence preserve their original names. They are not recommendations to call the active class Metamorph.
