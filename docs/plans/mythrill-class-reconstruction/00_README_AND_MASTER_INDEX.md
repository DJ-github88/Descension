## Authority and evidence labels

- **CONFIRMED:** implemented and reachable in current production code. Source reachability is not browser, multiplayer, tabletop, or deployment proof; state the verification level alongside it.
- **AUTHORED:** present in data/documentation; not proof of effect execution.
- **HISTORICAL:** Git/archive evidence; not current canon.
- **DESIGN INTENT:** creator's reconstruction instructions; approved direction, not code already changed.
- **PROPOSED:** recommendation awaiting approval.
- **UNRESOLVED:** insufficient/conflicting evidence or incomplete specification.
