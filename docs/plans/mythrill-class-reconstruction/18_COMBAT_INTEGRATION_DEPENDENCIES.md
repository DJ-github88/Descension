## Mandatory execution invariants

Validate costs, gains, exact entities, operation count, resource bounds and authority before applying. Recheck after awaits. Immediate coupled payment/consequence is one accepted command under its declared support; rejected action leaves no partial mutation. Rollback before commit is cancellation of a prepared intent; after acceptance there is no automatic refund. Retried exact command returns original receipt. Unknown outcome retains exact command/choice/roll and prevents speculative replay.

Simultaneous spend uses expected revisions and domain conservation. A second stale action revalidates without drawing/rerolling. Reconnect cannot regenerate a hand, rest budget, summon, anchor or form. Talent/heritage modifiers have named sources and apply once in the authored plan. GM authority still passes through the existing consequence validation rather than direct client writes to other actors.

## Unresolved shared rules

Range metric/area origin/partial overlap/walls/friendly fire/snapping/elevation; mitigation order and special defenses; reaction priority/payment/timing; durable cooldowns; event-linked effects; atomic N-actor choice. The current plan explicitly retains these dependencies. Designing a class does not settle them by implication.
