## Required contract body for every later unit

1. Task ID and precise approved goal.
2. Exact source evidence and source hashes/branch baseline.
3. Exact target files and existing code/data/tests to preserve.
4. Allowed and prohibited changes; no unrelated active-P-phase widening.
5. Full input/output/state/operation schema and version behavior.
6. Required mechanics, timing, affordability, events and effects.
7. UI/authoring/compact/expanded/accessibility/privacy requirements.
8. Test fixtures and positive/refusal/retry/concurrent/recovery cases.
9. Migration impact and complete stable-ID mappings, where relevant.
10. Dependencies and approval decisions; no implicit rule invention.
11. Observable acceptance criteria and exact verification commands.
12. Rollback preserving accepted consequences and original saves.
13. Expected artifacts and honest execution/support limits.

“Implement remaining spells/classes/heritages” is not a valid task. Each unit enumerates its records, mechanics and witnesses. If a target file moves before implementation, refresh the map rather than applying stale line ranges.
